Primer Ejercicio:
# Simulador de Ruleta de Opciones en C

Programa interactivo desarrollado en lenguaje C que simula una ruleta de opciones personalizable. Diseñado para ejecutarse en la consola de Windows y optimizado para entornos de desarrollo clásicos y modernos como **Dev-C++**.

## 🚀 Características Principales:
* **Configuración flexible:** El usuario puede elegir sortear entre **2, 3, 4 o 10 opciones**.
* **Entradas versátiles:** Permite ingresar palabras, números o símbolos especiales por teclado.
* **Interfaz mejorada:** 
  * Interfaz visual a **color** mediante la API de Windows (`windows.h`).
  * Contenido y resultados **centrados dinámicamente** en la pantalla.
  * Pantalla interactiva que permite **repetir el proceso** cuantas veces el usuario lo desee sin reiniciar la aplicación.
* **Validación robusta:** Control de errores ante ingresos de datos no válidos en la selección de opciones.

## ⚙️ Restricciones Técnicas Cumplidas:
* Sin uso de estructuras (`struct`).
* Sin arreglos bidimensionales (implementado mediante 10 arreglos unidimensionales independientes).
* Sin uso de punteros ni aritmética de punteros.
* Sin listas enlazadas ni estructuras de datos dinámicas.

## 🛠️ Compilación y Ejecución:
1. Abre el archivo en **Dev-C++** (asegúrate de guardarlo con la extensión `.c`).
2. Presiona **F11** para compilar y ejecutar automáticamente.
